## Claude Code Role

Sen bu projede uygulayıcı ajansın.

Çalışma biçimin:

1. Önce projeyi ve SPEC.md dosyasını oku.
2. Hemen tüm sistemi yazmaya çalışma.
3. Önce iskeleti kur:
   - Vite
   - React
   - TypeScript strict
   - Tailwind
   - React Router
   - Firebase config
   - Auth route yapısı
   - boş sayfalar
4. Projenin derlendiğini doğrula.
5. Sonra özellikleri sırayla ekle.
6. Her aşamada küçük, kontrol edilebilir değişiklik yap.
7. Commit atma.
8. Dosya değiştirmeden önce plan çıkar.
9. İş bitince:
   - değişen dosyaları listele
   - çalıştırılması gereken test/build komutlarını yaz
   - Codex review öner
